
# Информационная система управления персоналом кофейни

## Описание проекта

Программное приложение предназначено для автоматизации управления персоналом кофейни.

## Основные функции

- Учёт сотрудников.
- Управление рабочими точками.
- Составление графиков смен.
- Контроль рабочего времени.
- Формирование отчётов.

## Технологии

- Python 3.11
- Tkinter
- SQLite3
- Openpyxl

## Запуск программы

```bash
python main.py
```
